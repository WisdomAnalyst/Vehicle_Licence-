
Automatic Vehicle Number Plate Detection Web App 

> 🔧 Setup

Features

Image upload for number plate detection

Display detection results with bounding boxes and confidence scores


Setup

Create a virtual environment (optional but recommended):
-conda create -n vehicle_detection python=3.10 -y

Activate the virtual environment:
- conda activate vehicle_detection

Install the required dependencies:
- pip install -r requirements.txt

Run the flask application:
-python app.py

Open your browser and go to http://localhost:5000
